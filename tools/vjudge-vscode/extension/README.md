# CPE 練習題單：在 VS Code 點一題就開始

這個擴充套件是裝在**你的 Windows 電腦的 VS Code** 裡的題單介面。它以 [VJudge 文章 2679](https://vjudge.net/article/2679) 的分類、順序與題目為準，不自行換題。

## 使用前

1. 在 VS Code 開啟 `Codex_Try_001` 專案資料夾。此版本需要 VS Code 1.105.0 或更新版本；可以請本機 Codex 檢查你的版本，較舊時先更新 VS Code。
2. 更新到包含本擴充套件的助手版本。按照助手說明安裝其相依套件；擴充套件會使用專案裡的 `tools/vjudge-vscode/library.cjs`，因此安裝 VSIX 檔案本身不會取代助手更新。
3. 在 VS Code 的「擴充套件」頁面右上方 `…` 選「從 VSIX 安裝」，選擇本套件的 `.vsix` 檔案。VSIX 就是 VS Code 擴充套件的安裝檔。
4. 若 VS Code 提示重新載入，按重新載入。

## 每次練習

1. 點左側「CPE 練習」圖示，展開文章 2679 的分類。
2. 點一題。左邊顯示原始英文題目 PDF，保留圖形、表格與公式；右邊開啟你的 `main.cpp`。也可以切換「文字版」方便複製，或請旁邊的 Codex 解釋。
3. 自己寫解答。第一次開題只建立留白的 C++ 框架；已有程式、測資或題目筆記都保留。
4. 請 Codex 根據原題的官方範例建立 `practice/題號/tests/*.in` 與對應的 `*.out`，並逐字核對。擴充套件不猜測或自動拆分 PDF 裡的測資。
5. 按「測試（C++11）」。結果出現在 VS Code 下方的終端機；沒有測資時會回報失敗，不算測試通過。
6. 要送出時先按「查詢提交語言」。再按「提交這題」，輸入查得的語言名稱並確認本次提交。助手先儲存程式、執行對應語言的本機測試，通過後只提交一次，將提交編號與 AC／WA 等結果顯示在同一個 VS Code 的終端機。

給 Codex 的範例指示：

> 我正在練習 UVA-11332。請讀取 `.cpe-vjudge/library/2679/UVA-11332/題目.md`，用初學者的方式解釋題意；從原題的官方範例建立並核對測資，保留既有檔案，先不要替我解題或提交。

請將題號換成你點選的那一題。

## 檔案與登入

- 題單讀取只取得文章清單；點選一題才下載那題的 UVA 官方 PDF。已保存的原題會重用，不會整批下載。
- 原題保存在專案的 `.cpe-vjudge/library/2679/題號/`；自己的解答保存在 `practice/題號/main.cpp`。
- 閱讀這份公開題單與官方 PDF 不需要 VJudge 密碼，也不讀取本機登入資料。
- 線上提交仍使用既有本機助手保存的登入。登入失效或網站要求驗證時，依終端機提示手動重新登入。
- 重新讀取題單不會提交。選題不會提交。提交操作失敗也不會自動重送。
- 本機測試通過只表示保存的測資通過，不能代表線上 AC。線上結果以收到的那個提交編號為準。

## 驗證範圍

本套件有資料夾保留、題號限制、命令參數與安全顯示測試。完整測試結果與 Windows 安裝是否已實測，請以這次交付的說明為準；本文件不宣稱每台 Windows 都已驗證。
